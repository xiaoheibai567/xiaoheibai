# XH-01 演示串口协议

接口参数：115200 baud / 8N1。ASCII 指令，每条以 LF (\n) 结束。

| 命令 | 含义 | 预期返回 |
| --- | --- | --- |
| STATUS | 查询 LED 状态 | LED=ON 或 LED=OFF |
| LED_ON | 点亮 LED | LED=ON |
| LED_OFF | 熄灭 LED | LED=OFF |

库存由独立的 SQLite 数据库查询。控制前检查当前用户明确提出了控制请求。
若设备未回复，不能认定动作失败或成功，先用 STATUS 查询，避免重复执行。
这是一份虚构协议，真实设备需要烧录兼容固件；请勿将其当作厂商通用协议。
